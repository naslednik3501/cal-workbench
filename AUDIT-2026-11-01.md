# Проверка CAL Workbench 0.5 — 1 ноября 2026

## Объём

Изучены архитектура, документация, точки загрузки, хранение, состав пяти предоставленных ZIP и имеющиеся тесты. EXE и аппаратные скрипты не запускались. Это предварительный технический аудит, не сертификация алгоритмов и не проверка на реальном автомобиле.

## Подтверждено заново

- 71 файл исходного релиза совпал по размеру и SHA-256 с MANIFEST.json.
- `node tests/test_catalog.js`: PASS. 23 944 записи каталога имеют корректные размеры и SHA-256; ссылки index.html существуют.
- Полное сравнение с «Архивом 0»: все 23 944 записи совпали по пути, размеру и SHA-256.
- `node tests/test_catalog_store.js`: 8/8 PASS, включая атомарность операций, сохранение дубликатов, проверку хешей и отказ при недоступном хранилище. Используется Node-адаптер, не браузер.
- `node tools/audit.js`: 21 549 CAL прошли статический разбор; 4 имеют неподдерживаемые команды; 1 802 — неподдерживаемый формат либо ошибку разбора. Всего 23 355 CAL, 15 055 уникальных содержимых. Это не тест выполнения каждого калькулятора.

## Что осталось непроверенным

- `node tests/test_engine.js` завершился ENOENT на `rav4-original.bin` до прохождения тестов.
- `node tests/test_ui_state.js` завершился ENOENT на `ceed-original.bin` до прохождения тестов.
- Эталонные личные BIN намеренно исключены из исходного ZIP; их отсутствие не является установленной ошибкой приложения.
- Реальный браузер, CSS, IndexedDB браузера, импорт/выгрузка через HTTPS и работа с конкретным автомобильным блоком не проверены в этой сессии.
- Независимое сравнение с оригинальным iProg по одинаковым входам и параметрам не выполнено. Прежние сохранённые логи не заменяют такую проверку.

## Готовность к размещению

Приложение — статические HTML/CSS/JavaScript; сервер расчётов для текущих функций не требуется. Пути относительные, сборщик зависимостей не нужен. Новый скрипт `build_static.py` формирует папку только с веб-ресурсами, сохраняя их байты.

Первоначальная рекомендация закрытого хостинга отменена владельцем: выбран публичный репозиторий и GitHub Pages. Сайт и каталог будут общедоступны. Добавленные пользователем CAL останутся привязанными к браузеру и origin; исходный локальный импорт нужно перенести вручную. BIN не сохраняются в IndexedDB этим приложением.

Первоначальная проверка выполнена до создания репозитория. После неё владелец согласовал публичное размещение; создан репозиторий `naslednik3501/cal-workbench`. Результаты технических проверок выше относятся к исходной версии 0.5.
