# Compatibility checkpoint — 0.3

## Included source

Every non-directory/non-__MACOSX file from available `Calculators.zip` is present as original bytes in the catalog payload: 23,944 entries, including 23,355 CAL entries and 15,055 distinct CAL byte contents. Repeated paths/instances are retained. `archive-verification.json` records the new full archive comparison. `static-audit.json` records each CAL's static parsing outcome.

## Current implementation

- Encrypted binary CAL subset: decoding, supported form controls, reachable instruction validation, transactional VM.
- OnShow, OnApply, OnChange subset; read-only enforcement for the first and last.
- BIN comparison and editing; source/result downloads; JSON diff report.
- Per-user local CAL catalog; portable .calpack export/import; no BIN persistence.
- Original hardware operations, external EXE execution and online sharing are not implemented.

## Unsupported or unverified

- 1,802 CAL entries have unsupported format/form or parse failures; 4 have unsupported commands. They remain in the catalog.
- Text CAL source compilation, Lua, BC, IPR, IPP, BLR execution is not implemented.
- 21,549 CAL entries pass static parsing, not exhaustive execution or original-iProg equivalence.
- Arithmetic/control semantics are only partially validated; real-block results are not inferred from script messages.
- The application has no automatic common server catalog or publishing roles.
- Real-browser rendering, file-origin IndexedDB persistence and native Windows execution remain to be tested on the target browser.
