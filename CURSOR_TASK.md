# Задание Cursor: T-010A — изображения для калькуляторов

Назначено владельцем проекта 2026-11-02. Это готовое задание к выполнению, не просьба составить ещё один план.
Основной репозиторий: https://github.com/naslednik3501/cal-workbench
Оригиналы: https://github.com/naslednik3501/iprocal-sources

## Кратко

Найди среди уже исследованных изображений те, которые нужны интерфейсу калькуляторов для готовых BIN.
Подготовь проверенный список восстановления и возможного улучшения качества.
Параллельно chat-image-audit выполняет T-001 (исключение аппаратной части), поэтому ты не меняешь код, сборку и каталог.

## Сначала

1. Получи свежий main и прочитай AGENTS.md, PROJECT_SCOPE.md, TASKS.md, SOURCE_STORAGE.md и IMAGE-RESOURCE-AUDIT.md.
2. Проверь T-010A. Если она свободна/назначена Cursor и никто её ещё не выполняет, отметь «В работе»,
   свою уникальную подпись, дату и исходный commit в общем TASKS.md.
   Сохрани назначение на GitHub до основной работы. При конфликте обновления перечитай файл и сохрани чужие изменения.
3. Создай отдельную ветку `task/T-010A-images` от свежего main.
   Если ветка уже существует, сначала выясни по журналу, не является ли она продолжением этой же задачи.
4. Для начала достаточно основного репозитория. Если понадобились байты конкретной картинки,
   получи только её по инструкции SOURCE_STORAGE.md. Не клонируй всё хранилище исходников и не скачивай все ZIP.
   Если доступа нет, выполни доступный разбор таблиц и укажи, что визуальная проверка оригинала заблокирована.

## Исходные результаты — использовать, не повторять

- reports/image-visual-review-2026-11-02.csv — SHA-256, назначение, путь кандидата, пример CAL.
- reports/image-reference-groups-2026-11-02.csv — группы ненайденных ссылок.
- reports/image-resource-summary-2026-11-02.json — источники, контрольные суммы и подсказки расширений.
- IMAGE-RESOURCE-AUDIT.md — выводы и ограничения.

Это снимок прежнего парсера. В приложении теперь поддерживаются текстовые CAL:
старые числа не объявлять актуальными для всего нынешнего каталога.
Не пересматривай все 324 изображения только ради повторения уже записанной классификации.

## Что выполнить

1. Обработай все строки готового визуального CSV категорий `logo` и `device_identification`.
   Различай кандидат по имени и подтверждённую связь с конкретным CAL.
   Другие категории оставь T-001/T-002. Платы и инструкции не считать декорацией автоматически.
2. Для каждого кандидата проверь доступный контекст CAL и источник. Для связи, которую называешь подтверждённой,
   нужны конкретный CAL, SHA CAL, имя P-ресурса, SHA картинки, исходный путь и объяснение соответствия.
   Если одной картинки несколько вариантов или данных недостаточно, запиши «требует проверки»;
   не подставляй первую найденную.
3. Составь рекомендации:
   - восстановить оригинал;
   - можно заменить более качественным изображением того же объекта;
   - соответствие пока не установлено;
   - передать другому этапу с причиной.
4. Логотипам можно предложить более чёткое оформление. Фото магнитолы, панели, автомобиля или блока
   должно соответствовать именно той модели/поколению/версии, которую описывает CAL.
   «Более свежее» не означает изображение более новой модели автомобиля.
   Если нет проверенной замены, рекомендовать оригинал. Искать и скачивать массово картинки из интернета на этом этапе не требуется.
5. Проверь на нескольких конкретных примерах, действительно ли ресурс сейчас отсутствует,
   или старый отчёт уже не описывает текущее состояние. Фиксируй проверенный commit.
   Не запускай полный повторный аудит архивов.
6. Подготовь удобный итог по всем выбранным строкам; отдельно дай первые десять наиболее определённых
   пар CAL → изображение для последующего восстановления. Если доказанных пар меньше десяти, честно укажи число.

## Сохранить результат

Создай только:
- `reports/T-010A-image-proposals.json` — полный список решений с доказательствами, статусом проверки и исходным commit;
- `reports/T-010A-image-proposals.md` — короткий человеческий отчёт, итоги и приоритетные примеры.

Не публикуй исходные архивы, EXE, личные BIN или большие подборки изображений.
Сохрани файлы и отправь ветку на GitHub; открой PR, если доступна такая возможность.
Сам PR не сливай: отчёт будет использован при последовательном подключении ресурсов после T-001.
Обнови только запись T-010A и её журнал в TASKS.md на main, не перезаписывая чужие статусы.
Сообщи владельцу ссылку на ветку/PR и итог.

## Границы

Не менять `app.js`, `engine.js`, `cal-source.js`, `catalog*`, MANIFEST.json,
сборку, общие инструменты аудита, оригинальные CAL и изображения.
Не начинать T-001 и не брать её статус. Не удалять и не восстанавливать ресурсы на сайте.
T-010A — самостоятельная подготовительная подзадача; основной импорт T-010 остаётся отложенным.
Не заявлять исправление калькулятора по одному восстановленному изображению.
