# T-005: разбор 254 двоичных CAL

Дата завершения: 2026-11-04. Исходная версия: `209be427`.

## Результат

Все 254 версии из прежней группы `partial` разобраны по исходным байтам, заголовкам событий,
графам команд и адресуемым строкам. Байты CAL и исходные адреса событий не менялись.

| Состояние | CAL | Решение |
|---|---:|---|
| Рабочее чтение, адресуемого обработчика записи в оригинале нет | 216 | Чтение разрешено; ввод, `OnApply` и скачивание рассчитанного BIN заблокированы |
| Полный обработчик записи | 32 | Разрешён точным профилем SHA + событие + исходный адрес + конечный адрес строки |
| FIS с неподдержанной командой `0x4D` | 4 | Оставлены частично распознанными; переданы в T-003 |
| Пустые BP8272 | 2 | Оставлены недоступными: `OnShow` содержит только возврат, адрес `OnApply` недействителен |

Из 216 читателей у 214 адрес `OnApply` лежит за пределами расшифрованного CAL. Перестановка
байтов адреса, использование младшего байта и подстановка конца `OnShow` не восстанавливают
обработчик записи. У двух Honda Immo адрес `OnApply` точно совпадает с началом строки `CPI`,
на которую ссылается рабочий `OnShow`; команд записи по этому адресу нет.

В 32 писателях команды `OnApply` были целыми. Общий выход из события ведёт на начало уже
адресуемой таблицы строк. Старый разбор продолжал читать строку как команды и сообщал конец
файла, неизвестные `0xE3`/`0x6C` или отсутствующее поле 41. Разрешение ограничено точными
оригиналами в `binary-event-profiles.js`. Произвольные импорты и прежние 16 неподдержанных
двоичных CAL не получили новый статус.

## Проверка

- Проверен точный состав: 216 читателей, 32 писателя, 4 FIS и 2 недоступных BP8272.
- Для всех 32 писателей выполнены нулевой и детерминированный шаблон BIN с двумя значениями;
  исходный буфер остаётся неизменным, результат создаётся транзакционно.
- Для 21 из 32 писателей проверено совпадение результатов между десятью независимыми
  парами/тройками вариантов: Windstorm, H940S, KATO, Sprinter и шесть CFMOTO.
- Для BSI Partner D780949 зафиксирован точный ожидаемый результат: при значении 123456 на
  нулевом BIN меняются только байты `0xD3..0xD5` на `F2 CA 24`.
- Все 16 ранее полностью неподдержанных двоичных CAL остаются неподдержанными.
- Пройдены переносимые тесты каталога, исходного движка, Sportage, Polo, текстовых CAL,
  области проекта, хранилища и 465 пар CAL. Три сквозных сценария Chromium также пройдены.

Полный машинный состав находится в `binary-resolution-2026-11-03.json`; текущий общий аудит —
`calculator-coverage-binary-resolution-2026-11-03.json`. Проверки используют синтетические BIN
и не заменяют сравнение с оригинальным iProg или физическим блоком.
